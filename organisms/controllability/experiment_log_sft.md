# SFT experiment log — Organism 2 (controllability)

## v32 — cross-/within-family generalization study (2026-06-02)

### Why
Styles are paused: judges can't reliably grade them, which especially poisons RL
reward. We learned from v30/v31 that (a) long CoTs hurt generalization and (b)
generalization peaks early in training, then decays. With those dynamics
understood, v32 pivots from "can we teach styles" to a clean **generalization
map**:

1. Does training on one control *category* transfer to others? (cross-family)
2. Does training on a subset of a category transfer to held-out members?
   (within-family)
3. (Phase 2, see experiment_log_rl.md) Does RL on top of an SFT checkpoint —
   rewarding only the behaviors it was trained on — improve that generalization?

### Behavior universe (4 categories)
Everything is evaluated on **every** run (`eval_all: true`), so all run CSVs are
directly comparable.

- **Transforms** (26 mechanical families): case, terminator, marker-at-position,
  and the v32-new cadence/sentence families — `start_with_sentence`,
  `end_with_sentence`, `prefix_every_n_sentences`, `suffix_every_n_sentences`,
  `insert_sentence_every_n`, `prefix_sentences_with_sentence`,
  `suffix_sentences_with_sentence`. Deterministic graders.
- **Encoding** (2): `pig_latin`, `leetspeak`. Deterministic graders.
- **Language** (11): train `{spanish, german, chinese, russian, hebrew}`,
  held-out `{italian, dutch, polish, arabic, korean, hindi}` (+ french/pt/ja as
  extra eval). Within-family pairs: Romance es↔it, Germanic de↔nl, Slavic
  ru↔pl, Semitic he↔ar, East-Asian zh↔ko; hindi has no train counterpart
  (fully-unseen-family probe). LLM-graded (gemini language judge).
- **Information suppression** (3): `omit_word`, `omit_multiple_words`
  (deterministic absence grader; forbidden-word pools — train
  {because, therefore, the, answer} / eval {since, thus, is, result}),
  and `ignore_question` (eval-only, LLM-graded). `omit_topic` deferred (too hard
  to grade).

### Data regime
- **arc_c + csqa only** (2,621 raw CoTs, median ~1.7k chars) — the short-CoT
  lesson from v31_short, baked into source selection.
- Mechanical families (transforms, encodings) are produced on-the-fly by
  `transform_cot` + self-verify (~99.7% pass for encodings).
- Languages + suppression need LLM-rewritten CoTs (translate / omit-word), the
  same path styles use. Generated by `generate_language_rewrites.py` /
  `generate_suppression_rewrites.py` (gpt-5-mini, reasoning_effort=low; quality
  validated equal to medium at ~5× the speed), cleaned by `clean_rewrites.py`
  (empty/truncation/refusal + non-Latin script-presence check). Rewrite pool
  size (≈2,621 per train behavior) is decoupled from training-set size — the
  data builder subsamples. ~9% of CoTs trip OpenAI's content filter and are
  skipped (handled gracefully).

### Run matrix (per model; qwen3-14b first, gpt-oss-20b deferred)
"Train the category" = SFT on that whole category; eval everything.

| Config | Trains | Question it answers |
|---|---|---|
| `v32_transforms` | all 26 transforms | transforms → other categories |
| `v32_encoding` | pig_latin, leetspeak | encoding → other categories |
| `v32_language` | 5 train languages | language → others **and** → 6 held-out langs (within-family) |
| `v32_suppression` | omit_word, omit_multiple_words | suppression → others |
| `v32_transforms_within` | 5 of 26 transforms | within-transforms transfer to the 8 held out |

Language collapses cross- and within-family into one run (its train set *is* the
5 train-split languages; eval_all surfaces both at once). Mechanical runs
(transforms, encoding, transforms_within) need no generation and can run
immediately; language/suppression wait on their rewrite caches.

within-transforms split (`v32_transforms_within`):
- train: uppercase, alternating_case, prefix_sentences(marker), start_with(marker), exclaim_all
- held: lowercase, prefix_sentences(sentence), suffix_sentences(marker), suffix_sentences(sentence), start_with(sentence), end_with(marker), end_with(sentence), question_all

### Recipe (mirrors v31_short, the short-CoT winner)
LoRA r=1024 α=2048, lr=2e-4, grad_accum=16 (effective batch 16), 1 epoch,
`save_steps_list: [1,2,3,5,8,12,18,28,40,55,75,100,140,190,260,350]` (front-loaded
for the early-generalization trajectory), vllm_tp=1. To be tuned after the first
trajectory.

### Eval
`eval_all` evaluates the full universe (28 families + 14 languages + 3
suppression) on every checkpoint, independent of what was trained. Styles are
excluded (paused). Cost note: the dense trajectory × LLM-graded languages +
ignore_question is the main expense; a lite-mode that skips LLM-graded
modalities on intermediate checkpoints is a possible optimization if needed.
