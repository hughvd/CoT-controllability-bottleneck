One-line takeaways
================================================================================
1. More data (v9 = 7× v7) delivered big wins on lowercase_thinking (+0.50),
   end_with both pools (+0.48/+0.28), title_case (+0.20), but regressed on
   insert_word_every_third_word eval (-0.45) and prefix_sentences eval (-0.30).
2. Overall compliance barely moved (0.378 → 0.394 bool). More data helped
   some families, hurt others — net approximately flat.
3. compliance_score (continuous) is 0.426 — the bool undercounts partial
   compliance by ~3 points. Title_case 0.905 (very close to 0.95 threshold);
   alternating_case 0.463 (model is doing partial job); uppercase_thinking
   0.085 (model still barely tries uppercase).
4. Within-family marker generalization still clean on start_with (1.00 eval),
   end_with (0.88 eval), insert_between_words (0.75 eval). The concept is
   being learned for simple append/prefix operations.
5. Structural transforms (reverse_word_order, wrap_each_sentence_in_bracket,
   double_vowels) still at 0% — fundamental token-level SFT limitation.
6. Accuracy still 0.269 vs baseline 0.465 — 20-point regression. Truncation
   (45% NaN) and SFT damage both contribute. KL anchor or lower LR would
   be the next levers.
