# Seven-control banning and user-ICL comparison

This extends the completed four-task factorial experiment to the paper's seven
main control tasks: uppercase, leetspeak, Spanish, Chinese, sentence prefixes,
no-first-person, and omit word. Styles remain outside this main-paper task set.
The same three ban-experiment models are used: Qwen3-32B, OLMo-3.1-32B-Think,
and GLM-5.2. Each task has 30 questions and three samples per condition.

## Reuse and scope

The 4,320 responses under `controllability/results/ban_user_icl/v1/` are retained.
Only Chinese, sentence prefixes, and no-first-person are generated anew, under
`controllability/results/ban_user_icl/seven_controls_extension_v1/`: 3,240 new
responses. The full dataset contains 7,560 responses, 210 question–control pairs,
and 206 distinct questions. Each new task has all four matched conditions:
instruction only, banning, user ICL, and user ICL plus banning.

The extension's `reuse_audit.json` records that expanding the task list left all
old requests and cells identical, including donor assignments, grading specs,
messages, seeds, prompt token IDs, and model/sampling settings. Donors are selected
on the full original ten-task pool before filtering to the requested tasks.
The ICL question pool is retained; as documented in the manuscript, token prefilling
uses replacement questions for two Chinese pairs. This is a match of control tasks,
not a claim that every prefill/ICL question is identical.

The older standalone `fixed_opening_ban/v1` dataset is preserved separately.
Its prompts are not mixed with the factorial data: the latter consistently uses
the ICL donor's control instruction across all four conditions. In particular,
donor-derived forbidden words can differ from the older standalone experiment.
The new ban-only figure is the no-ICL half of the same seven-task factorial dataset.
Historical uninstructed controls are not extended; neither main ban figure uses them.

## Scoring

**Full generated reasoning compliance is the primary seven-task metric.** The
first token in a ban experiment is generated by the model, not supplied as a
compliant prefill. Its first sentence should therefore count for sentence-prefix
control. Using the older post-opening scorer would exclude the entire first
sentence and leave single-sentence responses without an assessable unit.
Full-trace scores already exist for all retained responses; no regeneration or
new paid judgments are needed for them. Both metrics remain available in the
summary CSVs, and post-opening prefix scores report their eligible response count.

Chinese uses the same Mandarin Chinese rubric/model as prefill and ICL.
Sentence-prefix and no-first-person checks reuse the existing deterministic
graders. Missing post-opening prefix opportunities are marked missing, not failed.
All full-trace outcomes are retained; empty reasoning scores zero and missing
answers count as incorrect. Task accuracy uses the same instructed questions.
The number of samples remains three; prefill/ICL's five samples are not required
for a valid task-matched mean, though they give those studies different precision.

Means weight all seven control tasks equally. Paired percentile intervals use
5,000 question-cluster bootstrap draws, sharing weights across conditions and
tasks. The four-task estimates remain archived and should not be compared to a
seven-task aggregate as if only the intervention changed.

## Execution and artifacts

The pinned local-model mask and hosted GLM rejection protocol are unchanged.
For five slow GLM cases, generation was resumed from the paid-response cache with
16 proposals per tail batch (after attempt 65) and an allowance of 4,096 proposals
per response, retaining the same $25 API spending cap. The lowest accepted attempt
index is still retained. Already completed responses were not regenerated; pending
API calls at interruption keep conservative cost reservations in the paid journal.
The extension additionally handles an initial token that decodes to an incomplete
UTF-8 character: preserve its native/local-retokenized ID, and score the stable
decoded prefix without inventing a replacement character in the reasoning.

Collection/scoring/analysis:

```sh
python3 controllability/mech/ban_user_icl_watch.py \
  --experiment-root controllability/results/ban_user_icl/seven_controls_extension_v1 \
  --seven-controls
```

Rebuild figures and tables from completed saved scores:

```sh
python3 controllability/mech/analysis/ban_user_icl_analysis.py --seven-controls
```

Outputs include the four-condition aggregate figure, the ban-only aggregate figure,
per-control appendix figures, means, paired effects, quality checks, and opening
frequencies. Aggregate figures also show task accuracy. PNG/PDF copies go to
`paper/figures/`; `paper.tex` prose is left for the author to update (seven tasks,
210 pairs/206 unique questions, and full generated reasoning scoring).
