# Instruction-only ICL failure onset

Source: the same four-model, eight-control instruction-only sample used by the current ICL figures (30 questions × 5 responses per model/control; 4,800 responses, none empty). No generation or grading calls were made. Run `python3 controllability/analysis/icl_failure_onset/analyze.py` to reproduce.

For uppercase, leetspeak, sentence prefixes, and numbered sentences, 2,068 / 2,113 responses below the existing binary compliance threshold (score < 0.5) violate their local constraint in the first non-whitespace token: **97.87%**. By model: Qwen14 600/600, Qwen32 600/600, OLMo31 598/598, GLM 270/315. Defining failure as any imperfect compliance instead (score < 1), the result is 2,088/2,205 = **94.69%**.

These percentages are conditional on these four tasks, not the full suite. Spanish's graded language fraction has no unambiguous token-local rule; sentence endings allow markers on either side of punctuation. Suppression failures are included separately in the diagnostic CSV, but do not support the same opening-failure claim. The saved no-first-person failure labels disagree with the current deterministic grader for 80 instruction-only responses: Qwen14 4, Qwen32 20, GLM 56. These saved scores were not changed. Do not present the six-task diagnostic denominator as a fully reconciled analysis.

Token boundaries are reconstructed from saved reasoning with the pinned tokenizer.json, not verified native generated token IDs. Leading whitespace is preserved and literal token-zero results are saved separately: all Qwen saved reasoning in the four-task failed subset begins with a whitespace token. Thus use **first non-whitespace token**, not literal first generated token. A word such as `Okay` and a following comma are treated as separate tokens according to the tokenizer. The model may have different native token boundaries or provider-normalized returned text; this is an audit of returned reasoning.

`per_response.csv` contains opening excerpts and onset positions; `summary.csv` includes both thresholds and denominators; `by_control.csv` gives task breakdowns; `provenance.json` records source/tokenizer hashes. For suppression the diagnostic position is the token containing the final character of the first forbidden word in hindsight, not a claim that the constraint became causally irreversible before the following word boundary.

## Spanish opening assumption (user-requested)
A fixed-seed random sample of 8 failed Spanish responses per model (32 total; seed 20260925) all opened with English prose. Examples and source row indices are in `spanish_opening_random_sample.csv`. Assuming all 513 failed Spanish responses fail at the opening yields (2,078 + 513) / 4,170 = 62.13% across the eight-task suite. This is conditional on that assumption, not an exhaustive token-local Spanish audit. Sentence-ending failures remain in the denominator and are not credited as opening failures. An English opening does not by itself establish that its first token is unambiguously non-Spanish (e.g. Okay is a loanword).

## Exhaustive Spanish opening census
All 600 instruction-only Spanish responses were inspected programmatically for a case-insensitive, leading-whitespace-tolerant whole-word `Okay` opening. Among the 513 saved failures: Qwen14 150/150, Qwen32 146/146, and OLMo31 150/150 start with `Okay`; GLM 0/67 do, and all 67 start with `The`. Thus all failed Spanish responses start with one of these two opening words. This replaces sample extrapolation with exhaustive opening-word counts, but Spanish first-token noncompliance remains an operational interpretation of an English-style opening, not a token-local language judgment. All 450 Qwen/OLMo Spanish responses (including the four passing Qwen32 responses) begin with `Okay`, so this opening does not itself imply failure of the whole-response language threshold. See `spanish_okay_counts.csv` and `spanish_all_openings.csv`.

## User and assistant ICL
`analyze_conditions.py` repeats the same audit for each condition (set ICL_CONDITION=user_icl or assistant_icl). `conditions_with_spanish.csv` includes the full-suite operational English-opening count. All 461 failed user-ICL Spanish responses begin with Okay (440), The (18), Alright (2), or Let's (1). All 462 failed assistant-ICL Spanish responses begin with Okay (438) or The (24). Counts concern generated target responses, not donor demonstrations. Threshold <0.5 and the original saved grades are retained; the no-first-person grader disagreement also applies to these conditions. Sentence-ending failures remain in denominators without credited opening violations.
