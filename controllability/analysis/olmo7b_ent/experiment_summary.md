# OLMo-3-7B Entrenchment Sweep

**Question: does more RL make the CoT format harder to redirect?**

## Motivation

Our diverse-SFT "controllability organism" teaches a model to reshape its
chain-of-thought on command (rewrite it in another language, apply a text
transform, encode it, or suppress reasoning). The open question for
monitorability is whether **reinforcement learning entrenches the CoT area** —
i.e. whether a model that has been RL'd harder becomes more resistant to having
its reasoning format redirected by downstream fine-tuning.

OLMo-3 is the natural testbed because its Think-path post-training is *fully
checkpointed*: SFT → DPO → RLVR (with intermediate RL step revisions). That lets
us hold the SFT control recipe fixed and vary **only the RL stage of the seed
model**, then ask how well the control still installs and generalizes.

## Setup

**Axis (5 checkpoints along the OLMo-3-7B Think post-training trajectory):**

| Tag | Checkpoint | RL amount |
|-----|-----------|-----------|
| `sft` | `Olmo-3-7B-Think-SFT` | none |
| `dpo` | `Olmo-3-7B-Think-DPO` | preference only |
| `rl_early` | `Olmo-3-7B-Think` @ `step_0350` | ~25% of RLVR |
| `rl_mid` | `Olmo-3-7B-Think` @ `step_0700` | ~50% of RLVR |
| `rl_final` | `Olmo-3-7B-Think` (main) | full RLVR |

> 7B has **no extended-RL (3.1) checkpoint** — that stage is 32B-only. Here we
> densely sample the 7B RLVR trajectory instead; the extended-RL "extreme" point
> is deferred to a 32B confirmation run.

**Per-checkpoint procedure** (the "baseline then finetune at that checkpoint"
design):

1. **Baseline eval** the raw checkpoint on the full eval set → its *intrinsic
   control floor* (how much it already complies with control instructions,
   soft + hard, per category).
2. **Diverse SFT** (`v33_diverse`, **frozen** recipe: LoRA r64, `max_steps` 203
   ≈ exposure-64, `max_length` 4096) seeded from that checkpoint.
3. **Eval the adapter** → in-distribution + held-out compliance, soft + hard, per
   category.
4. **Metric = held-out LIFT over that checkpoint's own baseline floor.**
   Entrenchment would show as the lift *shrinking* as we move rightward along the
   RL axis.

**Design invariants:**
- Lift is measured over each checkpoint's *own* floor — RL raises spontaneous
  instruction-following, so absolute compliance is confounded; only the lift is
  comparable across the axis.
- SFT recipe / rank / data / steps are identical across all 5 seeds; only the seed
  checkpoint varies.
- Training data is OLMo-native (`training_v33_diverse_olmo.csv`, 6498 rows, traces
  generated by `Olmo-3-32B-Think` over arc_c + csqa) — no cross-model
  self-distillation, and the same dataset is reused for every seed.
- OLMo eval uses `vllm_reasoning_parser: none` (the `<think>` block is recovered
  from content).

Hardware: 1×H200. Driver `scripts/run_olmo7b_entrenchment.sh` (prefetches the next
checkpoint during the current checkpoint's compute). Soft = `compliance_score`;
hard = graded compliance at the **0.95** threshold.

## Results

Held-out lift over each checkpoint's own baseline floor:

| Category | sft | dpo | rl_early | rl_mid | rl_final |
|----------|-----|-----|----------|--------|----------|
| **transforms** (soft) | 0.059 | 0.085 | 0.083 | 0.095 | **0.108** |
| **language** (soft)   | 0.150 | 0.123 | 0.186 | 0.168 | **0.080** |
| transforms (hard@0.95) | 0.038 | 0.056 | 0.065 | 0.072 | 0.076 |
| language (hard@0.95)   | 0.120 | 0.085 | 0.115 | 0.120 | 0.080 |
| **encoding** (soft)   | −0.009 | −0.011 | −0.010 | −0.004 | −0.010 |
| **suppression** (soft)| 0.006 | 0.000 | −0.012 | −0.006 | −0.025 |

**Finding: modality-split, NOT monotonic entrenchment.**

- **Transforms lift *rises* with RL** (0.059 → 0.108 soft, monotone; same trend
  hard). More RL makes the transform-control easier to install, not harder.
- **Language lift holds/climbs through mid-RL then *collapses* at the RL
  endpoint** (0.186 → 0.168 → **0.080**, roughly halving, in both soft and hard).
  This is late-RL entrenchment — but of the **language dimension only**.
- **Encoding and suppression are null throughout** (≈0 / slightly negative at every
  checkpoint) — the organism never installs these dimensions in OLMo-7B, so there
  is nothing to entrench.

The crossover — transforms rising while language collapses at `rl_final` — is the
headline of the sweep.

## Caveats

- 7B magnitudes are small and noisy; the `rl_final` language drop is the one clear,
  reproduced-across-metrics signal.
- 7B is a comparatively weak organism → a smaller/noisier entrenchment signal than
  we'd expect at 32B.
- The most interesting point — **extended RL (Olmo-3.1)** — does not exist at 7B.
  This run motivates a **32B confirmation**, especially at that extended-RL point.
